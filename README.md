# E-commerce-SQL-project
Designed an e-commerce relational database and performed sales, customer, and revenue analysis using SQL joins and aggregations.

**Project Overview**

This project focuses on building and analyzing an e-commerce database using SQL from a data science perspective. The main aim is to understand customer behavior, product performance, and order patterns by working with structured data stored in a relational database.

**Project Objectives**

The objective of this project is to design a normalized e-commerce database and perform data analysis using SQL. Through this project, meaningful insights are extracted related to customers, products, and orders. It also helps in strengthening analytical thinking and data handling skills that are important for a Data Scientist Intern role.

**Database Design**

The database is designed using multiple related tables including users, categories, products, orders, and order items. Normalization principles are followed to reduce redundancy and maintain data integrity. Relationships between tables are created using primary and foreign keys.

**ER Diagram**

The ER diagram represents the overall structure of the database and shows how different tables are connected to each other. It helps in understanding the flow of data between users, orders, products, and categories.

ER diagram image is available in the er-diagram folder of this repository.

**Data Analysis Using SQL**

This project includes analytical SQL queries that help analyze customer purchase behavior, product and category performance, and order details. Multiple table joins are used along with aggregation functions such as count and sum to generate useful insights from the data.

**Project Structure**

The repository is organized into separate folders for database creation scripts, sample data insertion, analytical queries, and the ER diagram. This structure makes the project easy to understand and reproducible.

**How to Run the Project**

The project can be executed using MySQL Workbench. First, the database and tables are created using the scripts provided. Next, sample data is inserted into the tables. Finally, analytical queries can be executed to explore and analyze the data.

**Tools and Technologies**

This project is implemented using MySQL and SQL. The ER diagram is created using draw.io, and the project is version controlled using GitHub.
